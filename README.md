
# 🚔 GARUDA - Anti Drug Consumption Data Analytics Dashboard
![](https://github.com/kdilli607-creator/anti_drug_data_analytics/blob/main/drugs-abuse-poster-clipart-signage-260nw-2634587939.jpg)
## 📌 Project Overview

GARUDA (Ganja Anti-Drug United Data Analytics) is an interactive data analytics dashboard developed using Microsoft Excel to analyze anti-drug consumption data and support data-driven decision making.

The dashboard helps visualize consumer profiles, drug consumption patterns, financial transaction details, crime history, and supply chain relationships through interactive charts and KPI indicators.

---

## 🎯 Project Objectives

* Analyze drug consumption patterns.
* Identify high-risk consumer groups.
* Monitor crime history and case status.
* Track financial transaction details.
* Analyze supplier and associate networks.
* Generate actionable insights using data visualization.

---

## 📊 Dataset Information

The dataset contains 1000 synthetic records and includes:

### Personal Details

* Police Station Name
* Consumer Name
* Age
* Father Name
* Mobile Numbers
* Test Results

### Address Details

* Present Address
* Permanent Address

### Social Media Information

* Gmail ID
* Instagram ID
* Facebook ID

### Financial Transaction Details

* Bank Name
* Account Number
* UPI IDs
* Linked Mobile Number

### Identity Details

* Aadhaar Number (Synthetic)
* Voter ID (Synthetic)
* PAN Number (Synthetic)

### Social-Economical Profile

* Occupation
* Monthly Income

### Drug Consumption Pattern

* Consumption Duration
* Consumption Frequency

### Supply Chain Mapping

* Co-Consumer Details
* Supplier/Peddler Information
* Main Source

### Purchase Modus Operandi

* Purchase Mode
* Usual Consumption Spot

### Crime History

* Police Station
* Crime Number
* Crime Year
* Section of Law
* Case Stage
* History Sheet Status
* Rowdy Sheet Status
